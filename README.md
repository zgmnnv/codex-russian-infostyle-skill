# Russian Infostyle Skill для Codex

Скилл для редактуры русского текста. Помогает написать понятную кнопку, объяснить условия доставки, сократить письмо или собрать статью из заметок. В ответ вы получаете готовый текст. По запросу Codex объяснит правки или предложит варианты.

## Пример

**Исходник**

> На крупные заказы действует скидка. Её размер зависит от объёма заказа и регулярности доставок.

**Правка для сайта магазина**

> На крупные заказы даём скидку. При расчёте учитываем объём заказа и регулярность доставок.

В исходнике понятно, к чему относится «её». Для сайта подходит формулировка от лица магазина. Она сохраняет оба условия расчёта скидки. В нейтральном описании условий можно оставить исходный текст.

## Установка в Codex

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив.
2. Скопируйте папку `skills/infostyle` целиком в `.agents/skills/` вашего проекта. Создайте каталог, если его ещё нет. В результате файл с инструкциями должен лежать по пути `.agents/skills/infostyle/SKILL.md`.
3. Откройте проект в Codex и вызовите скилл в чате:

```text
$infostyle Отредактируй письмо клиенту. Сохрани сроки и условия оплаты.
```

Добавьте текст письма в сообщение или укажите путь к файлу в проекте.

## Что внутри

В справочнике собраны **39 редакторских приёмов** с примерами и условиями применения. Они помогают сохранить смысл при сокращении, подобрать слова для интерфейса, проверить числа и передать голос автора. В основе примеров — разборы Главреда и Бюро Горбунова, книги Норы Галь «Слово живое и мёртвое» и Майи Богдановой «Школа контента». [Справочник приёмов](skills/infostyle/references/glavred-patterns.md)

## Как проверяли

В наборе 68 заданий. Для локальной проверки в Codex выбрали 20. С первого раза прошли 19. В одном рекламном баннере редактор придумал, что речь идёт о записи на событие. После уточнения инструкции этот кейс проверили повторно: редактор запросил недостающие сведения. [Ответы и результаты проверки](eval/sample-run.md) · [Критерии оценки](eval/criteria.md)
