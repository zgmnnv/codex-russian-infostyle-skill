# Russian Infostyle Skill для Codex

Плагин для редактуры русского текста в Codex. Помогает написать понятную кнопку, объяснить условия доставки, сократить письмо или собрать статью из заметок. В ответ вы получаете готовый текст. По запросу Codex объяснит правки или предложит варианты.

## Пример

**Исходник**

> На крупные заказы действует скидка. Её размер зависит от объёма заказа и регулярности доставок.

**Правка для сайта магазина**

> На крупные заказы даём скидку. При расчёте учитываем объём заказа и регулярность доставок.

В исходнике понятно, к чему относится «её». Для сайта подходит формулировка от лица магазина. Она сохраняет оба условия расчёта скидки. В нейтральном описании условий можно оставить исходный текст.

## Установка в Codex

Выполните две команды в терминале. Первая подключит каталог из этого репозитория, вторая установит плагин для всех ваших проектов.

```sh
codex plugin marketplace add https://github.com/zgmnnv/codex-russian-infostyle-skill.git --ref main
codex plugin add infostyle@zgmnnv-infostyle
```

Откройте новый чат в Codex. Передайте текст или укажите путь к файлу в проекте.

```text
$infostyle:infostyle Отредактируй письмо клиенту. Сохрани сроки и условия оплаты.
```

Если у вас уже установлен отдельный скилл, команда `$infostyle:infostyle` выберет версию из плагина.

## Обновление плагина

```sh
codex plugin marketplace upgrade zgmnnv-infostyle
codex plugin add infostyle@zgmnnv-infostyle
```

Посмотреть установленную версию можно командой `codex plugin list --marketplace zgmnnv-infostyle --json`. Номер версии указан в поле `version`.

## Что внутри

В справочнике собраны **39 редакторских приёмов** с примерами и условиями применения. Они помогают сохранить смысл при сокращении, подобрать слова для интерфейса, проверить числа и передать голос автора. В основе примеров — разборы Главреда и Бюро Горбунова, книги Норы Галь «Слово живое и мёртвое» и Майи Богдановой «Школа контента». [Справочник приёмов](skills/infostyle/references/glavred-patterns.md)

Для лендингов, тарифов, калькуляторов и форм есть памятка. Она помогает проверить, понятно ли предложение с первого экрана, откуда берутся числа и что произойдёт после нажатия кнопки. [Памятка по продуктовому тексту](skills/infostyle/references/product-copy.md)

## Как проверяли

В наборе 75 заданий. В первом локальном прогоне в Codex проверили 20 из них. С первого раза прошли 19. В одном рекламном баннере редактор придумал, что речь идёт о записи на событие. После уточнения инструкции проверили задание повторно, и редактор запросил недостающие сведения. [Ответы и результаты первого прогона](eval/sample-run.md) · [Критерии оценки](eval/criteria.md)
