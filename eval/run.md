# Проверка скилла на примерах

1. Из корня репозитория выбери задания в [test-cases.md](test-cases.md). В наборе есть исходные задания 1–56, ситуации для проверки приёмов 57–68 и задачи по продуктовому тексту 69–75. Для проверки чувствительности к контексту сопоставь, например, анонс в задании 58 и инструкцию в 68.
2. В новом чате Codex выбери скилл плагина через `$infostyle:infostyle` и передай только запрос и исходный материал. Сохрани каждый полный ответ в `eval/outputs/caseN.md`. Для одного задания можно передать оценщику этот файл, для серии — каталог.
3. Запусти `python3 eval/score.py eval/outputs/`. Состояние REVIEW означает, что ответ ещё нужно прочитать или что он изменился. Оценщик выведет SHA-256 текущего ответа.
4. Рецензент сопоставляет ответ с заданием по [четырём критериям](criteria.md) и сохраняет рядом `caseN.review.json`. В поле sha256 подставь отпечаток ответа, в note — наблюдения по этому кейсу, в четыре поля оценок — PASS или FAIL. Образец структуры:

```json
{
  "sha256": "<отпечаток из вывода>",
  "facts": "PASS",
  "meaning": "FAIL",
  "reader": "FAIL",
  "delivery": "PASS",
  "note": "В исходнике адреса нет. В ответе просят проверить уже готовый адрес. Форма короткого письма соблюдена."
}
```

5. Повтори запуск. Итоговый процент — доля ответов в выбранном прогоне, прошедших все четыре проверки. До завершения рецензирования итоговый процент не выводится. Для сравнения версий используй один и тот же перечень заданий. Код выхода 0 означает PASS, 1 — FAIL, 2 — неполный или некорректный прогон.
