# Слова и конструкции для проверки

Подсветка помогает найти место для анализа. Прочитай фразу до и после предполагаемого удаления. Если потерялись условие, точность, термин или интонация, сохрани их.

| Что привлекло внимание | Редакторское решение |
|---|---|
| Вводные слова («как известно») | Удали пустую вводную. Оставь «например», когда дальше действительно идёт пример. |
| Усилители («максимально») | Убери усилитель, если он ничего не добавляет. Срок или результат укажи, когда он известен. |
| Оценки («удобный») | Назови подтверждённое свойство. Учитывай точные названия на экране и авторские цитаты. |
| Указания на время («сейчас») | Проверь дату, переход между тарифами или временный характер состояния. |
| Корпоративные штампы | За словами об индивидуальном подходе ищи конкретную услугу. Запроси недостающий факт, если он нужен читателю. |
| Газетные штампы | Проверь, передаёт ли привычный образ авторскую мысль или стирает её. |
| Бытовые клише | В реплике человека они могут передавать его голос. |
| Канцеляризмы | Замени оборот понятным действием, сохрани исполнителя и условия. |
| Неопределённость | «Около» и «больше» описывают точность данных. Для замены на точное значение нужно основание. |
| Отглагольные существительные | Раскрой цепочку через действия. Сохрани официальное название, если читатель ищет его в интерфейсе. |
| Местоимения | Сохрани «мы» и «вы», если они разделяют ответственность. Для «её», «его», «их» прочитай соседние фразы вместе. Если связь ясна, местоимение можно оставить. При двусмысленности уточни предмет. [Пример со скидкой](glavred-patterns.md#описание-услуги-отвечает-на-вопрос-клиента) |
| Модальность | Различай возможность, обязанность и совет. Для необязательной операции подходит «можно». |
| Страдательный залог | Назови исполнителя, если он известен и важен. Для статуса может хватить результата. |
| Громкие обещания | Условия гарантии и сравнения требуют источника. |
| Цепочки определений | Приблизь уточнение к предмету. Проверь, к какому действию относится условие. |
