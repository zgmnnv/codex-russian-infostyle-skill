# Короткие примеры правки

| Контекст | Исходник | Возможная правка |
|---|---|---|
| Сервис сообщил о сбое загрузки. Причина неизвестна. | К сожалению, в процессе загрузки вашего файла произошла непредвиденная ошибка. | Не удалось загрузить файл. |
| Сервис подтвердил превышение лимита 8 МБ и разрешает выбрать другой файл. | Ошибка загрузки. | Файл больше 8 МБ. Выберите файл до 8 МБ включительно. |
| Письмо о передаче заказа перевозчику. | Спешим сообщить об успешной передаче вашего заказа в службу доставки. | Передали заказ в службу доставки. |
| Поле нужно для отправки чека. | Введите ваш адрес электронной почты для отправки электронного чека. | Подпись «Электронная почта», подсказка «На этот адрес пришлём чек». |
| На лендинге известно только назначение продукта. | Инновационный сервис для создания презентаций. | Сервис для создания презентаций. |
| Человек может удалить черновик без восстановления. | Вы уверены? ОК / Отмена | «Удалить черновик? Восстановить его не получится». Кнопки «Удалить черновик» и «Оставить». |

Другие примеры, включая развилки при недостатке фактов, — в [справочнике 39 приёмов](glavred-patterns.md).
